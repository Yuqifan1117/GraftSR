Two-file utility package with a thin public surface exposed through `__init__.py` (re-exports `ControlNetInput` and `Annotator`). `controlnet_input.py` defines a single `@dataclass` holding per-ControlNet parameters (id, scale, start/end scheduling, source image, and optional inpaint image/mask plus processor_id). `annotator.py` implements the `Annotator` class as a factory: its constructor maps a `Processor_id` literal to a specific `controlnet_aux.processor` detector, lazily importing each dependency only when needed. The annotator normalizes output resolution back to the input image size and exposes a `to(device)` method for moving underlying models to a device. Dependency direction is one-way: this module depends on `diffsynth.core.device.npu_compatible_device` for device selection and on the external `controlnet_aux` library; nothing in the rest of diffsynth imports internals beyond the two re-exported symbols.
