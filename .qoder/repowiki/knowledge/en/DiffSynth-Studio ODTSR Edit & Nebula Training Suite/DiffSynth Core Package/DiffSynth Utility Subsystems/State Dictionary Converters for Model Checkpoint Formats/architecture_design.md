Each file in this package implements one or more pure Python converter functions (e.g. `FluxDiTStateDictConverter`, `WanVideoDiTFromDiffusers`, `LTXModelStateDictConverter`) that take a PyTorch `state_dict` mapping of string keys to tensors and return a new `state_dict` with renamed/reshaped keys. There is no shared base class or registry — each module is self-contained and imported directly by callers. Converters fall into two patterns: (1) simple prefix stripping / key rewriting via explicit `rename_dict` mappings, and (2) block-structured transformations that iterate over `double_blocks`/`single_blocks` or `transformer_blocks`/`single_transformer_blocks` prefixes and apply suffix-level renames. Some converters also perform tensor operations (concatenation, reshaping) when merging split projections (e.g. q/k/v → qkv, or splitting final linear layers). The `__init__.py` is empty, so the package exposes modules rather than a centralized API.
