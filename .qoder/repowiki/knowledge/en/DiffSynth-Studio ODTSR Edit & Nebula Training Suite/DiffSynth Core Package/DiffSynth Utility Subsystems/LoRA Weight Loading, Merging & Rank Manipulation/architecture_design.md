The module is organized around a base loader class `GeneralLoRALoader` in `general.py`, which parses `.lora_A`/`.lora_B` (or legacy `.lora_down`/`.lora_up`) weight pairs, handles deprecated alpha scaling, and fuses LoRA weights into a target `torch.nn.Module`. `flux.py` extends this with `FluxLoRALoader` that adds source-format detection (diffusers vs. civitai) and two large rename tables (`diffusers_rename_dict`, `civitai_rename_dict`) to remap parameter names; it also provides the standalone `FluxLoRAConverter` with static methods `align_to_opensource_format` and `align_to_diffsynth_format` for bidirectional conversion between DiffSynth's internal format and the open-source Civitai/SDXL-style format. `merge.py` exposes `merge_lora` to horizontally concatenate A-weights and vertically concatenate B-weights across a list of LoRA dicts. `reset_rank.py` provides `reset_lora_rank` which recomputes A/B factors via `torch.pca_lowrank` to enforce a target rank. The package re-exports only `GeneralLoRALoader`, `merge_lora`, and `reset_lora_rank` through `__init__.py`, keeping the Flux-specific classes internal to `flux.py`.
