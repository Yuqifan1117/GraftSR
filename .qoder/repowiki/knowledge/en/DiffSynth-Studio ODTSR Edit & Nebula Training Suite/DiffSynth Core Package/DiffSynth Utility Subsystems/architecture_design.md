Each subpackage is self-contained and exposes its public API through a minimal `__init__.py` that re-exports only the symbols consumers need (e.g. `ControlNetInput`, `Annotator`, `GeneralLoRALoader`, `ses_search`, xfuser USP functions). There is no shared base class or registry across subpackages; they are independent toolkits consumed by higher-level DiffSynth modules. The `state_dict_converters/` package follows a per-model-file pattern where each converter targets one checkpoint layout and is imported on demand rather than auto-discovered. Cross-package communication does not occur — consumers import from whichever subpackage matches their need (e.g. a pipeline loads media via `utils.data`, applies ControlNet via `utils.controlnet`, merges LoRAs via `utils.lora`, and converts checkpoints via `utils.state_dict_converters`).
