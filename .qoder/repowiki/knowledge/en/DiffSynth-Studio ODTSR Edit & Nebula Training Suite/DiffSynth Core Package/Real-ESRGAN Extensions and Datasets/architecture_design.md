The module is organized under `diffsynth/extensions/` with a single subpackage `realesrgan/`. The core degradation logic lives in `realesrgan.py`, which defines the `RealESRGAN_degradation` class exposing multiple degradation strategies: `degrade_process`, `degrade_process_with_score`, `light_degrade_process`, `dual_degrade_process`, and `video_screenshot_degrade_process`. Dataset classes (`dataset.py`, `dataset_mask.py`, `dataset_resume_index_mask.py`, `dataset_resume_last_mask.py`, plus legacy copies) implement PyTorch `Dataset`s that instantiate `RealESRGAN_degradation` on-the-fly during training. A separate `zmrepair.py` defines the `ZMLiveRepair` UNet-style network built from reusable `DoubleConv`, `TripleConv`, `DownConv`, `UpCatConvResNet`, and `ResnetBlock` blocks. The top-level `__init__.py` is empty, so consumers import directly from `diffsynth.extensions.realesrgan.*`. Dependencies flow one-way: datasets depend on the degradation class; no cross-imports between dataset variants.
