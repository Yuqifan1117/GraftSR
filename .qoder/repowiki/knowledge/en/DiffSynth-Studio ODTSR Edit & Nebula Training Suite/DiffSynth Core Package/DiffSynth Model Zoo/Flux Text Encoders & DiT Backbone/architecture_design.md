Three focused modules form a two-tier architecture: `flux_text_encoder_t5.py` wraps `transformers.T5EncoderModel` as `FluxTextEncoderT5` to provide the Flux-1 prompt encoder; `flux2_text_encoder.py` wraps `transformers.Mistral3ForConditionalGeneration` as `Flux2TextEncoder` for the Flux-2 multimodal text encoder. `flux2_dit.py` is the core DiT model (`Flux2DiT`) composed of `Flux2TransformerBlock` (double-stream with cross-attention via `Flux2Attention` + `Flux2AttnProcessor`) and `Flux2SingleTransformerBlock` (single-stream parallel attention+MLP via `Flux2ParallelSelfAttention` + `Flux2ParallelSelfAttnProcessor`). Both attention classes expose a pluggable `processor` attribute with `_default_processor_cls` / `_available_processors` class attributes, delegating all QKV projection, RoPE application, and SDPA dispatch through `..core.attention.attention_forward`. Positional encoding uses `Flux2PosEmbed` with per-axis `get_1d_rotary_pos_embed`, while conditioning flows through `Flux2TimestepGuidanceEmbeddings` → `Flux2Modulation` producing shift/scale/gate triplets applied via AdaLayerNorm-style modulation in each block. Gradient checkpointing is supported through `..core.gradient.gradient_checkpoint_forward`.
