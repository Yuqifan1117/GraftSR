Three cooperating files form a layered architecture around the Qwen2.5-VL backbone:
- `nexus_gen.py` defines `NexusGenAutoregressiveModel`, a thin `torch.nn.Module` wrapper that constructs a `Qwen2_5_VLForConditionalGeneration` from a hard-coded `Qwen2_5_VLConfig`, loads a `Qwen2_5_VLProcessor`, and exposes high-level `forward(instruction, ref_image, num_img_tokens)` methods for both editing (with a reference image) and pure text-to-image generation. It builds chat messages, substitutes `<image>` placeholders with the tokenizer's image token, and extracts target image embeddings by masking input/image/prefill tokens.
- `nexus_gen_ar_model.py` contains the core autoregressive model: a subclass of `Qwen2_5_VLPreTrainedModel` plus `GenerationMixin` that overrides `_sample`, `prepare_inputs_for_generation`, `prepare_image_position_ids`, and `get_rope_index` to support streaming image-token generation (vision_start → image* → vision_end). It also re-implements `Qwen2_5_VLProcessor` as a `ProcessorMixin` wrapping an AutoImageProcessor and Qwen2 tokenizer, and defines the `Qwen2_5_VLCausalLMOutputWithPast` output type.
- `nexus_gen_projector.py` provides the building blocks reused by the merger: `Qwen2_5_VLRotaryEmbedding`, `Qwen2_5_VLAttention`, `Qwen2MLP`, `Qwen2RMSNorm`, and `Qwen2_5_VLDecoderLayer`. `NexusGenImageEmbeddingMerger` stacks N decoder layers plus a RMSNorm→Linear→RMSNorm→ACT→Linear→RMSNorm projector to map LLM hidden states into a diffusion-compatible channel space, with its own mRoPE position-id computation. `NexusGenAdapter` is a small two-layer adapter module.

Dependency direction is one-way: `nexus_gen.py` imports from `nexus_gen_ar_model.py`, which in turn imports transformer internals; `nexus_gen_projector.py` is self-contained and imported only by higher-level code (not by the AR model itself), acting as a separate component library. Each major module exposes a `state_dict_converter()` static method for loading weights from different sources (Civitai/Diffusers).
