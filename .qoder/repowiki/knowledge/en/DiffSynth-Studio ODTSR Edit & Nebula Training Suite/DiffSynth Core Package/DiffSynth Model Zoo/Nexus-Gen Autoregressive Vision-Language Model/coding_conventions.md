- Each major module exposes a `state_dict_converter()` static method returning a converter object with `from_civitai` and/or `from_diffusers` methods for weight-format translation.
- Configuration dictionaries are constructed inline using `Qwen2_5_VLConfig(**{...})` with the same hard-coded key set (`_name_or_path`, `architectures`, `rope_scaling.mrope_section`, etc.) repeated across modules to ensure consistency.
- Vision-language token handling follows a fixed protocol: chat templates are applied via `processor.apply_chat_template`, `<image>` placeholders are replaced with the tokenizer's image/video tokens, and masks are derived from `input_ids == model.config.image_token_id` / `vision_start_token_id` / `vision_end_token_id`.
- Multimodal RoPE is computed through a dedicated `get_rope_index` / `get_position_ids` helper that produces a `(3, B, L)` tensor of temporal/height/width position IDs, used consistently in both the AR model and the merger.
- Generation loops override `_sample` and `prepare_inputs_for_generation` rather than calling `generate` directly, manually managing `is_sampling_img`, `num_img_tokens`, and the vision_start/vision_end token boundaries.
