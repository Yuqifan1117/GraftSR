Three cooperating modules form the LTX-2 pipeline:
- `ltx2_dit.py` defines the core DiT backbone: `Attention` (RMSNorm + RoPE via `apply_rotary_emb` with INTERLEAVED/SPLIT modes), `BasicAVTransformerBlock` (video self-attn, cross-attn with audio, FFN), AdaLN-single conditioning via `AdaLayerNormSingle`, and `TransformerArgsPreprocessor`/`MultiModalTransformerArgsPreprocessor` that assemble timestep, positional embeddings, and cross-modal scale-shift-gate parameters. Perturbation support (`PerturbationType`, `PerturbationConfig`, `BatchedPerturbationConfig`) enables STG-style attention skipping.
- `ltx2_text_encoder.py` extends `Gemma3ForConditionalGeneration` from transformers, adding `LTXVGemmaTokenizer` and post-processing via `LTX2TextEncoderPostModules` which projects multi-layer hidden states through `GemmaFeaturesExtractorProjLinear` or `GemmaSeperatedFeaturesExtractorProjLinear`, then passes them through `Embeddings1DConnector` (a 1D transformer with learnable registers replacing padded tokens).
- `ltx2_video_vae.py` provides a causal 3D UNet-style VAE built from `ResnetBlock3D`, `DualConv3d` (factorized spatial+temporal convs), `CausalConv3d`, `SpaceToDepthDownsample`/`DepthToSpaceUpsample`, and `VideoLatentPatchifier`. It supports tiling via `SpatialTilingConfig` with trapezoidal blending masks for memory-efficient inference.
All three share utilities from `ltx2_common` (e.g. `rms_norm`, `Modality`, `PixelNorm`, `SpatioTemporalScaleFactors`) and reuse RoPE frequency computation (`precompute_freqs_cis`, `generate_freq_grid_pytorch/np`).
