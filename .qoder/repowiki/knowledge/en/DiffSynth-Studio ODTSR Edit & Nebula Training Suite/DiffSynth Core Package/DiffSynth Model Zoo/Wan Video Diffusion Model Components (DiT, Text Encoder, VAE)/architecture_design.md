Three independent PyTorch `nn.Module` classes form the pipeline:
- `wan_video_dit.py` defines `WanModel`, a 3D DiT built from stacked `DiTBlock`s that combine self-attention, cross-attention (with optional image context), and gated MLPs. Attention is dispatched through a `flash_attention` wrapper that selects among FlashAttention v3/v2, SageAttention, or SDPA based on availability. Positional encoding uses 3D rotary embeddings (`precompute_freqs_cis_3d`). Optional `WanToDanceInjector` injects audio/music features at selected transformer layers, and a `SimpleAdapter` control branch fuses camera latents.
- `wan_video_text_encoder.py` implements a T5-style encoder (`WanTextEncoder`) with relative positional embeddings, plus a `HuggingfaceTokenizer` wrapper around `AutoTokenizer` with configurable text cleaning pipelines.
- `wan_video_vae.py` provides a causal 3D VAE (`VideoVAE_`) composed of `Encoder3d`/`Decoder3d` stacks built from `CausalConv3d`, `ResidualBlock`, and `AttentionBlock`. Chunked inference is supported via an explicit `feat_cache`/`feat_idx` mechanism that caches the last `CACHE_T=2` time steps across causal convolutions.

Dependency direction is one-way: the DiT imports `gradient_checkpoint_forward` from `..core.gradient` and optional modules from sibling packages (`wan_video_camera_controller`, `wantodance`); the text encoder depends only on `transformers`; the VAE is self-contained. There is no shared base class — each file exposes its own top-level model class.
