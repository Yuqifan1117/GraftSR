Three independent `torch.nn.Module`-based submodules share no internal imports between them and each lives in its own file:
- `flux_dit.py` defines the diffusion transformer (`FluxDiT`) built from alternating `FluxJointTransformerBlock` (cross-modal attention over prompt + image tokens) and `FluxSingleTransformerBlock` (self-attention on image tokens). Positional encoding uses a custom `RoPEEmbedding` with per-axis frequencies; conditioning is injected via `TimestepEmbeddings`, `AdaLayerNorm`/`AdaLayerNormSingle`, and a pooled text embedder. An optional `entity_masks` path builds a block-sparse attention mask for multi-entity prompting. The module's `forward` is a stub — actual orchestration happens in `pipelines.flux_image`.
- `flux_vae.py` provides `FluxVAEEncoder` (3→16 latent channels) and `FluxVAEDecoder` (16→3 RGB), each composed of `ResnetBlock`, `VAEAttentionBlock` (with either `ConvAttention` or `Attention`), and `UpSampler`/`DownSampler` stages. A shared `TileWorker` class implements overlap-and-add tiling via `torch.nn.Unfold/Fold` to reduce VRAM during inference; both encoder and decoder expose a `tiled_forward` entry point.
- `flux_text_encoder_clip.py` implements a 12-layer CLIP-style encoder (`FluxTextEncoderClip`) with token + fixed positional embeddings, causal masked self-attention, and `clip_skip` support that returns both pooled and final-layer hidden states.
Dependency direction is one-way: all three files import only from `torch`, `einops`, and the shared `general_modules` utilities; there are no cross-imports among the three files.
