Three cooperating modules form the MoVA audio side of the model:
- `mova_audio_dit.py` defines `MovaAudioDit`, a thin subclass of `WanModel` from `..models.wan_video_dit`. It replaces the video patch embedding with a 1-D Conv1d, precomputes 1-D RoPE frequencies via `precompute_freqs_cis_1d`, and runs gradient checkpointing over its parent blocks.
- `mova_audio_vae.py` implements `DacVAE`, an encoder-decoder audio codec built from `EncoderBlock`/`DecoderBlock` stacks of dilated `ResidualUnit`s wrapped in weight-normalized 1-D convolutions. It supports two latent modes: discrete via `VectorQuantize`/`ResidualVectorQuantize` (factorized codes, L2-normalized codebook) or continuous via a diagonal Gaussian posterior (`DiagonalGaussianDistribution`). The `forward` returns a dict keyed by `audio`, `z`, `codes`, `latents`, and either `vq/*` losses or `kl_loss`.
- `mova_dual_tower_bridge.py` provides `DualTowerConditionalBridge`, which registers bidirectional `ConditionalCrossAttentionBlock` modules at selected layer indices chosen by `CrossModalInteractionController` (strategies: shallow_focus, distributed, progressive, custom, full). Cross attention optionally applies RoPE via `RotaryEmbedding` and can use per-frame pooled AdaLN (`PerFrameAttentionPooling`) on the conditioning stream. A helper `build_aligned_freqs` aligns video frame positions to audio-step units using the configured `audio_fps`.

Dependency direction is one-way: the bridge imports shared primitives from `..models.wan_video_dit` (`AttentionModule`, `RMSNorm`) and both the DiT and bridge use `..core.gradient_checkpoint_forward` for memory-efficient training. There is no coupling between the VAE and the DiT/bridge files within this scope; they are assembled externally.
