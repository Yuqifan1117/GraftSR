Three cooperating files form a small utility layer around LTX2's latent-space representations:
- `ltx2_common.py` defines the canonical data shapes (`VideoPixelShape`, `VideoLatentShape`, `AudioLatentShape`, `SpatioTemporalScaleFactors`), the frozen `LatentState` used during diffusion denoising, a `Modality` dataclass bundling tokens/timesteps/positions/context, the `Patchifier` Protocol with `patchify`/`unpatchify`/`get_patch_grid_bounds`, and shared normalizers (`NormType`, `PixelNorm`, `build_normalization_layer`, `rms_norm`).
- `ltx2_audio_vae.py` implements the full audio VAE: an `AudioProcessor` (mel spectrogram via torchaudio), an `AudioPatchifier` implementing the `Patchifier` protocol, causal/non-causal `CausalConv2d` + `make_conv2d`, residual blocks (`ResnetBlock`, `ResBlock1/2`), attention (`AttnBlock` + `make_attn`), encoder/decoder paths built by `build_downsampling_path` / `build_upsampling_path`, a `PerChannelStatistics` normalizer, and the `LTX2AudioEncoder` that wires everything together.
- `ltx2_upsampler.py` provides N-dimensional pixel-shuffle upsampling (`PixelShuffleND`), anti-aliased `BlurDownsample`, a rational `SpatialRationalResampler`, and the top-level `LTX2LatentUpsampler` which stacks ResBlocks around a configurable spatial/temporal upsample path; a helper `upsample_video` wraps it with per-channel statistics from `LTX2VideoEncoder`.

Dependency direction is one-way: `ltx2_audio_vae.py` imports only from `ltx2_common`; `ltx2_upsampler.py` imports the common shapes and additionally references `LTX2VideoEncoder` from a sibling module. No file imports the other two utility files, keeping them loosely coupled through the shared shape/protocol layer.
