Three cooperating modules extend the base `wan_video_dit` DiT architecture:
- `wan_video_dit_s2v.py` defines `WanS2VModel`, a DiT variant that injects motion latents via `FramePackMotioner` (multi-resolution 3D conv projections with 3D RoPE), fuses audio through `CausalAudioEncoder` + `AudioInjector_WAN` (CrossAttention injected at selected `DiTBlock`s), and uses `WanS2VDiTBlock` with modulated AdaLayerNorm. It also provides `torch_dfs` traversal to discover DiTBlocks and `rope_precompute` for 3D rotary embeddings over concatenated reference/motion frames.
- `wan_video_motion_controller.py` provides `WanMotionControllerModel`, a small MLP that maps a scalar `motion_bucket_id` into a 6×dim timestep modulation vector via sinusoidal embedding, used to drive motion intensity.
- `wan_video_camera_controller.py` generates Plücker ray embeddings from camera poses (`generate_camera_coordinates`, `process_pose_file`, `ray_condition`) and exposes `SimpleAdapter` (PixelUnshuffle → Conv → ResidualBlock) to project them into the DiT feature space; `Camera.process_camera_coordinates` is a convenience wrapper.
Dependency direction: both controllers feed conditioning signals into `WanS2VModel`; the S2V model imports shared primitives (`rearrange`, `precompute_freqs_cis_3d`, `DiTBlock`, `Head`, `CrossAttention`, `modulate`, `sinusoidal_embedding_1d`) from `wan_video_dit` and gradient checkpointing from `core.gradient`.
