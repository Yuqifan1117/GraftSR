Three cooperating modules form two diffusion backbones:
- `anima_dit.py` defines the `MiniTrainDIT` video DiT built from `PatchEmbed`, stacked `Block`s (self-attn + cross-attn + MLP), `FinalLayer`, and two positional embedding strategies (`LearnablePosEmbAxis` and `VideoRopePosition3DEmb`). It uses an `operations` abstraction for Linear/LayerNorm/RMSNorm to allow backend swapping, and delegates attention to `..core.attention.attention_forward` via `torch_attention_op`. Time conditioning flows through `Timesteps` → `TimestepEmbedding` with optional AdaLN-LoRA.
- `joyai_image_dit.py` implements `JoyAIImageDiT`, a PixArt/SD3-style model with a `WanTimeTextImageEmbedding` conditioner and a stack of `MMDoubleStreamBlock`s that process image and text streams in parallel, merge them into a single attention window, and apply separate AdaLN modulation per stream. RoPE is generated via `get_nd_rotary_pos_embed` with configurable `rope_dim_list`.
- `joyai_image_text_encoder.py` wraps `transformers.Qwen3VLForConditionalGeneration` as `JoyAIImageTextEncoder`, configuring a Qwen3-VL text+vision config and hooking the final language-model norm to return pre-norm hidden states for cross-attention.

Dependency direction: both DITs depend on `..core.attention` and `..core.gradient` utilities; the text encoder depends only on `transformers`. The three files are independent entry points consumed by higher-level model loaders.
