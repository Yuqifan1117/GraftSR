Three independent PyTorch `nn.Module` subclasses live side-by-side in this leaf module:
- `qwen_image_controlnet.py` defines `BlockWiseControlBlock` (a linear-GELU-linear residual block with RMSNorm on both inputs) stacked into `QwenImageBlockWiseControlNet`, which projects conditioning tensors and exposes a `blockwise_forward` hook keyed by `block_id` to inject control signals at specific transformer layers.
- `qwen_image_image2lora.py` builds `ImageEmbeddingToLoraMatrix` via two `CompressedMLP` branches that output LoRA A/B matrices; `LoRATrainerBlock` chains several such heads over the four Qwen-Image pattern groups (`attn.*`, `img_mlp/*_mod`, `attn.add_*`, `txt_mlp/*_mod`) and `QwenImageImage2LoRAModel` instantiates one per transformer block, emitting a flat state-dict of LoRA weights keyed by full parameter paths.
- `siglip2_image_encoder.py` subclasses HuggingFace `SiglipVisionTransformer` and `Siglip2VisionModel` to attach a fixed-size image processor and a simplified forward that returns either a pooled embedding or the last hidden state, using `sdpa` attention and NPU-aware device selection via `diffsynth.core.device.npu_compatible_device`.
Dependency direction is outward only: these modules import from `general_modules` (RMSNorm), `transformers` (SigLIP configs/processors), and the local device helper; they are not imported by each other.
