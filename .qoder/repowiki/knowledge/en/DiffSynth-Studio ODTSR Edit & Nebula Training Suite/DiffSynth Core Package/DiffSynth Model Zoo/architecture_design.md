Each child file defines one complete model family as a set of PyTorch `nn.Module` classes (DiT backbone, text/image encoders, VAE, adapters). Cross-cutting concerns are centralized in two files: `general_modules.py` provides reusable primitives (timestep embeddings, RMSNorm, AdaLayerNorm, Diffusers-compatible timestep projection) that every model imports; `model_loader.py` exposes a `ModelPool` that discovers models by hashing their checkpoint files against a global `MODEL_CONFIGS` registry, dynamically importing the declared `model_class`, and loading weights through a shared `load_model` pipeline with optional VRAM offloading via `AutoWrappedModule`. Models communicate only through well-defined tensor contracts (embeddings, latents, conditioning tensors); there is no runtime coupling between families — they are selected at load time by matching the checkpoint hash to a config entry.
