Three cooperating PyTorch modules form the QwenImage pipeline:
- `qwen_image_dit.py` defines the DiT backbone (`QwenImageDiT`) built from stacked `QwenImageTransformerBlock`s that jointly attend to image and text tokens via `QwenDoubleStreamAttention`. Positional encoding uses custom RoPE (`QwenEmbedRope`, `QwenEmbedLayer3DRope`) supporting both 2D spatial and 3D video (frame×height×width) sequences, with an optional 3D-RoPE mode. Attention falls back between `flash_attn_interface.flash_attn_func` (with optional FP8 path) and `torch.nn.functional.scaled_dot_product_attention`. Conditioning is injected through `TimestepEmbeddings` and AdaLayerNorm; DualLoRA modulation is supported via per-token shift/scale/gate parameters.
- `qwen_image_text_encoder.py` wraps `transformers.Qwen2_5_VLModel` with a hand-crafted `Qwen2_5_VLConfig` (28 layers, hidden_size=3584, rope_theta=1e6) and returns `hidden_states` as prompt embeddings.
- `qwen_image_vae.py` provides a 3D causal VAE (`QwenImageVAE`) composed of `QwenImageEncoder3d` → quant_conv → post_quant_conv → `QwenImageDecoder3d`. All temporal convolutions use a custom `QwenImageCausalConv3d` with feature caching (`CACHE_T=2`) for streaming inference. Tiled encode/decode delegates to `TileWorker` from `.tiler`.

Dependency direction: the DiT depends on shared primitives in `general_modules` (`TimestepEmbeddings`, `RMSNorm`, `AdaLayerNorm`); the VAE depends on `tiler`; the text encoder depends only on `transformers`. There is no cross-import among the three files — they are assembled by higher-level orchestration code.
