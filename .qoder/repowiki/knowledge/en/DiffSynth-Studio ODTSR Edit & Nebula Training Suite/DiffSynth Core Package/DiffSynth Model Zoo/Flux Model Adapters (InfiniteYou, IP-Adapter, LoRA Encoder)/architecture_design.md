Three independent `torch.nn.Module` adapters live side-by-side in this package, each targeting a different conditioning signal for Flux:
- `flux_infiniteyou.py` defines `InfiniteYouImageProjector`, a Perceiver-style transformer (learned queries + stacked `PerceiverAttention` + `FeedForward` blocks) that maps an image embedding to a fixed number of latent tokens; paired with `FluxInfiniteYouImageProjectorStateDictConverter` that remaps diffusers state dict keys.
- `flux_ipadapter.py` builds `FluxIpAdapter` from an `MLPProjModel` projecting a `SiglipVisionModelSO400M` output into per-block `IpAdapterModule`s that produce `(ip_k, ip_v)` pairs injected into attention via `scale`; includes `FluxIpAdapterStateDictConverter` for both diffusers and civitai formats.
- `flux_lora_encoder.py` provides a reusable `Attention`/`CLIPEncoderLayer`/`SDTextEncoder` stack plus a `LoRAEmbedder` that flattens LoRA A/B weights through `LoRALayerBlock`s into a concatenated embedding, wrapped by `FluxLoRAEncoder` with special tokens; paired with `FluxLoRAEncoderStateDictConverter`.

Each adapter follows the same interface pattern: a main `nn.Module` class exposing a `forward()` and a static `state_dict_converter()` method returning a converter object with `from_diffusers` / `from_civitai` methods. There is no shared base class — adapters are self-contained and intended to be plugged into a larger Flux pipeline by the caller.
