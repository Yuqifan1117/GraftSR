Two small, independent sub-packages under `diffsynth/core/`:
- `device/`: `npu_compatible_device.py` defines runtime availability flags (`IS_CUDA_AVAILABLE`, `IS_NPU_AVAILABLE`) and a thin wrapper around `torch.cuda` / `torch.npu` namespaces via `get_torch_device()`. It exposes helpers for device type detection (`get_device_type`, `parse_device_type`), ID/name resolution, synchronization, cache clearing, NCCL/HCL backend selection (`get_nccl_backend`, `parse_nccl_backend`), and bf16 precision tuning. The package `__init__.py` re-exports only the public API surface.
- `gradient/`: `gradient_checkpoint.py` implements `gradient_checkpoint_forward`, which chooses among three paths — DeepSpeed `checkpointing.checkpoint` (when configured), PyTorch `autograd.graph.save_on_cpu` + `utils.checkpoint`, or a plain forward call — based on boolean flags passed at call time. Helper factories `create_custom_forward` and `create_custom_forward_use_reentrant` wrap modules so they can be passed into checkpointers.
Dependency direction is one-way: callers import from these two packages; neither imports from each other. Both are pure-Python wrappers around `torch` (and optionally `deepspeed`).
