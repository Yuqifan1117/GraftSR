Three cooperating modules exposed through `__init__.py`:
- `config.py` defines the `ModelConfig` dataclass that normalizes input (`path` vs `model_id`), resolves download source (ModelScope or HuggingFace) via environment variables `DIFFSYNTH_DOWNLOAD_SOURCE` / `DIFFSYNTH_SKIP_DOWNLOAD` / `DIFFSYNTH_MODEL_BASE_PATH`, and produces a `vram_config()` dict.
- `file.py` provides low-level state-dict I/O: `load_state_dict` dispatches to `.safetensors` (via `safetensors.safe_open`) or `.bin` (via `torch.load` with `weights_only=True`), plus key-hashing utilities (`hash_state_dict_keys`, `hash_model_file`) for model fingerprinting.
- `model.py` orchestrates model instantiation: `load_model` constructs the model inside an initialization context (`skip_model_initialization` or DeepSpeed ZeRO3), optionally wraps parameters in `DiskMap` for lazy loading, applies a `state_dict_converter`, and can enable VRAM management via `enable_vram_management`. `load_model_with_disk_offload` is a convenience wrapper that forces all offload/onload devices to disk.
Dependency direction is one-way: `model.py` → `file.py` → `safetensors`/`torch`; `config.py` depends only on standard library + download clients. The package has no internal sub-packages — it is a flat utility layer consumed by higher-level engine code.
