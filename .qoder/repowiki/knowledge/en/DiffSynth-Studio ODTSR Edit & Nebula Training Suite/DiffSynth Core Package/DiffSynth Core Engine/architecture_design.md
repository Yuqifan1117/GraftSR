The `diffsynth/core` package is an orchestration layer that composes several independent subsystems into a unified engine. The `loader` module instantiates models and resolves weights (safetensors/PyTorch) from local or remote sources, then delegates memory management to `vram`, which wraps modules with lazy parameter loading and disk-backed state dicts. `device` abstracts CUDA/NPU/CPU selection and is consumed by both `loader` and `vram`. `gradient` provides checkpointing used during training, while `data` supplies operator-based transformation pipelines and a unified dataset consumed by training loops. `attention` implements the core attention mechanism used by all transformer-based models loaded through `loader`. All subsystems are re-exported via `core/__init__.py`, so consumers import from `diffsynth.core` as a single surface.
