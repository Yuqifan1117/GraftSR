The module is split into two cooperating layers:
- `operators.py` defines the operator abstraction (`DataProcessingOperator`) and a chainable `DataProcessingPipeline` built on Python's `__rshift__` operator, enabling expressions like `ToAbsolutePath(base_path) >> LoadImage() >> ImageCropAndResize(...)`. Concrete operators cover type conversion (`ToInt`, `ToFloat`, `ToStr`), I/O (`LoadImage`, `LoadVideo`, `LoadGIF`, `LoadAudio`, `LoadAudioWithTorchaudio`, `LoadTorchPickle`), geometry (`ImageCropAndResize`), sequencing (`SequencialProcess`, `ToList`), routing by extension or runtime type (`RouteByExtensionName`, `RouteByType`), and path resolution (`ToAbsolutePath`). Video/audio loading share a `FrameSamplerByRateMixin` for consistent frame-rate-aware sampling.
- `unified_dataset.py` exposes `UnifiedDataset(torch.utils.data.Dataset)` which reads metadata from JSON/JSONL/CSV (or falls back to scanning `.pth` cache files), then applies a `main_data_operator` plus optional `special_operator_map` per key. Static helpers `default_image_operator` and `default_video_operator` compose common pipelines using the operator DSL.
- Dependency direction is one-way: `unified_dataset.py` imports all operators; operators have no dependency on the dataset layer. The package re-exports only `UnifiedDataset` via `__init__.py`.
