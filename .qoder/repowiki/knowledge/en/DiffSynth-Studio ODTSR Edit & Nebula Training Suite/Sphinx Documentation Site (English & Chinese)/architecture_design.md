The docs module is a pure documentation tree built with Sphinx. Each language (en/, zh/) mirrors the same directory layout: index.rst as the root toctree, conf.py for Sphinx configuration, Makefile for build targets, and .readthedocs.yaml for Read the Docs hosting. Content is organized into six top-level sections — Pipeline_Usage, Model_Details, Training, Developer_Guide, API_Reference/core, and Research_Tutorial — all referenced from index.rst via toctree directives. The Sphinx config (conf.py) enables autodoc/autosummary/numpydoc/Myst parser extensions, reads version from ../../diffsynth/version.py, and uses sphinx_rtd_theme. Markdown (.md) and reStructuredText (.rst) sources are both supported via source_suffix = ['.rst', '.md']. A shared requirements.txt at the repo root pins docutils, myst_parser, recommonmark, sphinx>=5.3.0, sphinx-book-theme, sphinx-copybutton, sphinx-autobuild, sphinx-rtd-theme, sphinx_markdown_tables, sphinxcontrib-mermaid, and pymdown-extensions.
