Python with PIL/Pillow for image I/O, `openai` SDK for generic chat completions, Alibaba `dashscope` SDK for Qwen VLM/LLM/embedding/image-generation APIs, `requests` for HTTP calls, `dotenv` for API key loading, `tqdm` for progress bars, and `sklearn.metrics.pairwise.cosine_similarity` for similarity-based filtering. Models are primarily Qwen family (qwen3.5-plus, qwen3-vl-flash, qwen-image-2.0-pro) with Gemini fallback for image editing.
