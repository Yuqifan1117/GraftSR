Requires `OPENAI_API_KEY`, `OPENAI_BASE_URL`, and `DASHSCOPE_API_KEY` environment variables loaded via `.env`. Run pipelines through the provided shell scripts, e.g. `bash annotate_test.sh` or `bash convert_annotation_to_dataset.sh <annotation_list.json> <output_dir>`. The `annotate.py` script supports loop-based multi-pass filtering controlled by `--loop-filter-iterations` and parallel processing via `--num-workers`.
