The module is organized as a collection of standalone example scripts rather than a library. `model_inference/` and `model_inference_low_vram/` contain single-file pipelines that construct a `MovaAudioVideoPipeline` via `ModelConfig` entries pointing to HuggingFace safetensors (video_dit, video_dit_2, audio_dit, dual_tower_bridge, audio_vae, VAE, T5 encoder). `acceleration/unified_sequence_parallel.py` shows multi-GPU inference through `use_usp=True` with `torch.distributed`. `model_training/train.py` defines a `MOVATrainingModule` subclassing `DiffusionTrainingModule`, which builds the same pipeline, splits units via `split_pipeline_units`, and switches to training mode with `switch_pipe_to_training_mode`; it supports SFT and direct distillation tasks via a `task_to_loss` map. Training scripts under `full/` and `lora/` are shell wrappers invoking `accelerate launch` with different `--trainable_models` flags and timestep boundaries to train high-noise vs low-noise DIT branches separately. Validation scripts under `validate_full/` and `validate_lora/` mirror the inference pattern for evaluation.
