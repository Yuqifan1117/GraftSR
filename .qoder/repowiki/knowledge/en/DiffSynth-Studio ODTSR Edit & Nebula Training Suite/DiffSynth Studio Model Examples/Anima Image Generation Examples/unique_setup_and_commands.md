Datasets are fetched via `modelscope download --dataset DiffSynth-Studio/diffsynth_example_dataset --include "anima/anima-preview/*" --local_dir ./data/diffsynth_example_dataset`. Full fine-tuning runs `accelerate launch examples/anima/model_training/train.py` with `--trainable_models dit`; LoRA fine-tuning uses the same script but sets `--lora_base_model dit --lora_target_modules '' --lora_rank 32`. Low-VRAM inference configures per-model offload/onload dtype/device to disk and passes `vram_limit` to `from_pretrained`.
