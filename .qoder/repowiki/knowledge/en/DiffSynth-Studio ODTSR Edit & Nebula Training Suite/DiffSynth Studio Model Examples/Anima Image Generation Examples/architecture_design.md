The module is organized into three top-level example categories under `examples/anima/`: `model_inference/` and `model_inference_low_vram/` contain single-file Python scripts that instantiate `AnimaImagePipeline.from_pretrained` with a list of `ModelConfig` entries pointing to split safetensors files (diffusion model, text encoder, VAE) plus two tokenizer configs; `model_training/` provides the central `train.py` which defines an `AnimaTrainingModule` subclassing `DiffusionTrainingModule`, wiring together dataset loading via `UnifiedDataset`, loss selection through a `task_to_loss` map (`sft`, `direct_distill`, and their `:data_process` variants), and task dispatch via a launcher map. Training entry points are shell scripts in `full/` and `lora/` subdirectories that invoke `accelerate launch train.py` with different hyperparameters and either `--trainable_models dit` or LoRA flags (`--lora_base_model`, `--lora_target_modules`, `--lora_rank`). Validation scripts in `validate_full/` and `validate_lora/` load trained checkpoints back into the same pipeline for inference verification.
