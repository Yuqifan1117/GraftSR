Each `.sh` script first downloads the dataset via `modelscope download --dataset DiffSynth-Studio/diffsynth_example_dataset ...` before launching training with `accelerate launch examples/flux2/model_training/train.py`. Full-parameter runs use `accelerate_config.yaml` (DEEPSPEED, bf16, 8 processes), while LoRA runs split data processing (`task sft:data_process`) and training (`task sft:train`) into two separate accelerate launches. Low-VRAM inference sets `vram_limit=torch.cuda.mem_get_info('cuda')[1]/(1024**3)-0.5` and uses float8/disk offloads.
