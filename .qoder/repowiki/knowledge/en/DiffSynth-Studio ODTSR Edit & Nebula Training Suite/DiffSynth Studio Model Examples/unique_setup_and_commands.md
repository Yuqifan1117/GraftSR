Each model directory is independently runnable: inference via `python <script>.py`, low-VRAM inference via the parallel `model_inference_low_vram/` scripts, full fine-tuning through `bash model_training/full/<model>.sh`, LoRA fine-tuning through `bash model_training/lora/<model>.sh`, and validation via `python model_training/validate_*/<model>.py`. The dev_tools `webui.py` provides a single interactive interface across all models.
