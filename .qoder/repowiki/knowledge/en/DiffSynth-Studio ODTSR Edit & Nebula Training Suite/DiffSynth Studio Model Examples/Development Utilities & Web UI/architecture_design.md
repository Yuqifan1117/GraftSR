Three independent scripts with no shared package structure:
- `fix_path.py` is a self-contained utility that recursively scans `.md` files under `doc/zh` and `doc/en`, builds a filename-to-path map, and rewrites relative `.md` links to absolute paths.
- `unit_test.py` is a test orchestrator that discovers unprocessed `.sh`/`.py` scripts under `examples/<model>/...`, runs them sequentially or in parallel across NUM_GPUS processes using `CUDA_VISIBLE_DEVICES`, captures logs into `data/<script_path>/<script>/log.txt`, and moves generated media artifacts into per-script output folders. It exposes one test function per model family (`test_qwen_image`, `test_wan`, `test_flux`, `test_z_image`).
- `webui.py` is a Streamlit application that dynamically introspects `diffsynth.pipelines` via `pkgutil`/`inspect` to discover all subclasses of `BasePipeline`, parses their `from_pretrained` and `__call__` signatures, and renders typed Streamlit widgets (text, numbers, file uploaders, nested containers) driven by `draw_ui_element_safely`. Model configs can be auto-populated from example files via regex parsing of `ModelConfig(...)` lines. Progress is bridged from `tqdm` to `st.progress` through `StreamlitTqdmWrapper`. The app uses `st.session_state` to persist pipeline class, loaded pipe instance, and results across Streamlit's rerun cycle.
