Training is launched through shell scripts in `model_training/{full,lora,special}/*/*.sh` which call `accelerate launch` with the corresponding `accelerate_config*.yaml`. Inference scripts run directly with `python model_inference/<script>.py` or `python model_inference_low_vram/<script>.py`. Dataset inputs must follow diffsynth's `UnifiedDataset` format with `dataset_base_path`, `dataset_metadata_path`, and image operators enforcing 16-pixel height/width division.
