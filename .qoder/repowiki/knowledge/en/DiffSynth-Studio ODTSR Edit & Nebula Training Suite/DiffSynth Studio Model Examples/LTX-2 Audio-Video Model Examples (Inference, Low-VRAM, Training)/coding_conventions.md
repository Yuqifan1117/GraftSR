- Each example script constructs the pipeline by calling `LTX2AudioVideoPipeline.from_pretrained` with a list of `ModelConfig` objects, one per submodule (transformer, text_encoder_post_modules, video_vae_decoder, audio_vae_decoder, audio_vocoder), rather than loading a single monolithic checkpoint.
- VRAM management is expressed through a `vram_config` dict with keys `offload_dtype`, `offload_device`, `onload_dtype`, `onload_device`, `preparing_dtype`, `preparing_device`, `computation_dtype`, `computation_device`, passed as `**vram_config` to every `ModelConfig`.
- Scripts accept both the official `Lightricks/LTX-2` checkpoint pattern (`ltx-2-19b-dev.safetensors`) and the repackaged `DiffSynth-Studio/LTX-2-Repackage` pattern (`*.safetensors`), with the repackaged path kept as the active default and the official path left as a commented alternative.
- Output is always written via `write_video_audio_ltx2(video, audio, output_path=..., fps=24, audio_sample_rate=24000)` rather than custom I/O code.
- Training scripts follow a fixed argument schema parsed by `add_general_config` / `add_video_size_config` plus LTX-2–specific flags (`--tokenizer_path`, `--frame_rate`, `--initialize_model_on_cpu`, `--extra_inputs`, `--fp8_models`, `--offload_models`, `--task`), and dispatch execution through a `launcher_map` keyed by task string.
