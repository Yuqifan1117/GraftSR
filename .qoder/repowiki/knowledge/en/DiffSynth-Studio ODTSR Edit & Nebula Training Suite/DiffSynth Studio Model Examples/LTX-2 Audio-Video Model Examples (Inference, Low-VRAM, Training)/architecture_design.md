The module is organized into three parallel top-level directories, each mirroring the same set of LTX-2 pipeline variants:
- `model_inference/` — standalone inference scripts using `LTX2AudioVideoPipeline.from_pretrained` with a list of `ModelConfig` entries that load submodules (transformer, text encoder post-modules, video/audio VAE decoders, audio vocoder) separately from either the official `Lightricks/LTX-2` or the repackaged `DiffSynth-Studio/LTX-2-Repackage` checkpoints.
- `model_inference_low_vram/` — identical scripts but tuned for constrained VRAM by switching offload/onload/computation dtypes to `float8_e5m2` and passing an explicit `vram_limit` to `from_pretrained`.
- `model_training/` — a single `train.py` entry point defining `LTX2TrainingModule(DiffusionTrainingModule)` which builds the same `LTX2AudioVideoPipeline`, splits it via `split_pipeline_units`, and switches to training mode through `switch_pipe_to_training_mode`. It supports tasks `sft:data_process`, `sft`, `sft:train`, `direct_distill*`, and dispatches them via a `launcher_map`.

Subdirectories under `model_training/` provide shell launchers (`full/*.sh`, `lora/*.sh`) for two-phase splited training (data preprocessing then actual training), validation scripts under `validate_full/` and `validate_lora/`, and helper scripts to split model state dicts. All examples depend on `diffsynth.pipelines.ltx2_audio_video` and `diffsynth.utils.data.media_io_ltx2`; there is no internal Python package — each `.py` file is self-contained.
