- Every inference script constructs `WanVideoPipeline.from_pretrained` with a `model_configs` list of `ModelConfig` entries specifying `model_id` and `origin_file_pattern` for the diffusion, tokenizer, and VAE components, then calls the pipeline with a prompt/negative_prompt and saves the result via `save_video`.
- Training scripts follow a fixed argument pattern: `--dataset_base_path`, `--dataset_metadata_path`, `--height`/`--width`, `--dataset_repeat`, `--model_id_with_origin_paths` (comma-separated model_id:path pairs), `--learning_rate`, `--num_epochs`, `--remove_prefix_in_ckpt`, `--output_path`, and `--trainable_models`.
- Each model variant has a one-to-one correspondence across directories: the same base filename appears in `model_inference/`, `model_inference_low_vram/`, `model_training/full/`, `model_training/lora/`, `model_training/validate_full/`, and `model_training/validate_lora/` so users can swap between inference, low-VRAM inference, full training, LoRA training, and validation by changing the directory.
- Accelerate configurations are stored as YAML files (e.g. `accelerate_config_14B.yaml`, `accelerate_config_zero3.yaml`) under `model_training/full/` and referenced via `--config_file` rather than inline arguments.
