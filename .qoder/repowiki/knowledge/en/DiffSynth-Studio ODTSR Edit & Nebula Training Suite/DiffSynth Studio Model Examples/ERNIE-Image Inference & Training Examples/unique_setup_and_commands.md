Training requires downloading the example dataset via `modelscope download --dataset DiffSynth-Studio/diffsynth_example_dataset --include "ernie_image/Ernie-Image-T2I/*" --local_dir ./data/diffsynth_example_dataset`. Full fine-tuning is run with `bash examples/ernie_image/model_training/full/ERNIE-Image.sh` (uses DeepSpeed ZeRO3 config), LoRA fine-tuning with `bash examples/ernie_image/model_training/lora/ERNIE-Image.sh`, and inference scripts are executed directly with Python (`python examples/ernie_image/model_inference/ERNIE-Image.py`).
