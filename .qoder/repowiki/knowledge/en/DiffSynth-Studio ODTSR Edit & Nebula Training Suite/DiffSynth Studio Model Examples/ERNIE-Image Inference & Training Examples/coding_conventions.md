- Inference scripts construct pipelines by calling `ErnieImagePipeline.from_pretrained` with a list of `ModelConfig` objects, each specifying a `model_id` (HuggingFace repo) and an `origin_file_pattern` matching safetensors paths for transformer/text_encoder/vae/tokenizer.
- Low-VRAM inference reuses the same `from_pretrained` API but augments each `ModelConfig` with a `vram_config` dict containing `offload_dtype/device`, `onload_dtype/device`, `preparing_dtype/device`, and `computation_dtype/device` keys, plus a `vram_limit` parameter.
- Training scripts follow a uniform pattern: define a subclass of `DiffusionTrainingModule`, implement `get_pipeline_inputs` and `forward`, register task-specific loss lambdas in a `task_to_loss` dict, and dispatch via a `launcher_map` keyed by the `--task` argument.
- Shell entry points use `accelerate launch` with explicit `--dataset_base_path` and `--dataset_metadata_path` arguments, and pass model components through a single `--model_id_with_origin_paths` string joined by commas with colon-separated origin patterns.
- Turbo variant scripts differ from standard inference only by swapping the transformer `model_id` to `PaddlePaddle/ERNIE-Image-Turbo` and adjusting `num_inference_steps=8`, `cfg_scale=1.0`, and adding `sigma_shift=4.0`.
