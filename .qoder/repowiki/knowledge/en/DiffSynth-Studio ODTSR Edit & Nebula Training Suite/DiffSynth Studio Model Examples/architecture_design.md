Each model subdirectory (anima, ernie_image, flux, flux2, joyai_image, ltx2, mova, qwen_image, wanvideo, z_image) follows a uniform layout: `model_inference/` and `model_inference_low_vram/` contain per-script Python entry points, while `model_training/` is split into `full/`, `lora/`, `validate_full/`, `validate_lora/`, and optional `special/` (NPU, fp8, low-vram, split, differential, trajectory_imitation) subfolders with matching `.sh` launch scripts and shared `train.py`. Cross-model consistency is enforced by the shared DiffSynth pipeline APIs; dev_tools provides a common WebUI and test harness that introspects these pipelines. There is no runtime wiring between children — each example is self-contained and invoked directly via its own script or shell wrapper.
