The module is organized into three parallel example categories under `examples/flux/`: `model_inference/` (standard GPU inference), `model_inference_low_vram/` (VRAM-constrained inference with float8 offloading), and `model_training/` (training workflows). Each category contains one script per supported model variant (FLUX.1-dev, Kontext, Krea, IP-Adapter, Controlnet variants, LoRA Encoder/Fusion, EliGen, InfiniteYou, Nexus-Gen, Step1X-Edit, FLEX.2-preview). Inference scripts use `diffsynth.pipelines.flux_image.FluxImagePipeline.from_pretrained` with a list of `ModelConfig` entries pointing to HuggingFace model IDs and safetensor file patterns. The training entry point `model_training/train.py` defines a `FluxTrainingModule` subclassing `DiffusionTrainingModule`, which builds the same pipeline, splits trainable units, and dispatches tasks (`sft`, `direct_distill`) via a `task_to_loss` map. Training is orchestrated through shell scripts in `model_training/full/` and `model_training/lora/` that call `accelerate launch` with shared `accelerate_config.yaml` files (DeepSpeed ZeRO-2, bf16 mixed precision). Validation scripts live under `model_training/validate_full/` and `model_training/validate_lora/`. A special `npu_training/` subdirectory provides NPU-specific training shells.
