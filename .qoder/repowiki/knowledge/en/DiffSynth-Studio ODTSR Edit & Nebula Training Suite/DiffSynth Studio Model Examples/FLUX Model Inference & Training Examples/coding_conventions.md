- Each model variant gets its own dedicated Python or shell file named after the model (e.g. `FLUX.1-dev.py`, `FLUX.1-Kontext-dev.sh`), kept in parallel directories across inference, low-vram inference, and training subfolders.
- Inference scripts construct the pipeline by passing a list of `ModelConfig(model_id="black-forest-labs/FLUX.1-dev", origin_file_pattern="...")` entries to `FluxImagePipeline.from_pretrained`, separating backbone, text encoders, and autoencoder components.
- Training scripts follow a uniform pattern: download dataset with `modelscope`, then `accelerate launch train.py` with explicit `--dataset_base_path`, `--dataset_metadata_path`, `--model_id_with_origin_paths`, `--output_path`, and `--remove_prefix_in_ckpt "pipe.dit."` arguments.
- LoRA configuration consistently specifies `--lora_base_model "dit"`, a comma-separated `--lora_target_modules` list covering attention and MLP modules, `--lora_rank 32`, and `--align_to_opensource_format` to match open-source LoRA naming conventions.
- Low-VRAM inference scripts define a `vram_config` dict with paired `*_dtype` / `*_device` keys (`offload`, `onload`, `preparing`, `computation`) and pass it as `**vram_config` to each `ModelConfig` along with a computed `vram_limit`.
