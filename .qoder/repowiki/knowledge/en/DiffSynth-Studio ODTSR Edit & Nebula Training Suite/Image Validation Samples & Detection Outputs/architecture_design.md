This module is a flat data directory containing only static assets — no source code. It holds three categories of files: (1) original input images in JPEG/PNG format (both HQ and LQ variants), (2) per-image `.txt` annotation files listing bounding boxes as four-coordinate lines (x1,y1,x2,y2), and (3) derived visualization outputs (`_detected_regions_vis.png`, `_mask.png`, `_enhance.png`, `_ref_crop*`) produced by the processing pipeline for each input image. The naming convention ties all artifacts of a single image together via a shared base filename prefix, enabling automated pairing between inputs, ground-truth boxes, and generated results.
